🔒 PostgreSQL Row Level Security (RLS) Policy Snippet

Examiners frequently ask: "How do you enforce privacy between farmers at the database level?" Here is our exact SQL implementation: 

-- Enable RLS on fields table
ALTER TABLE fields ENABLE ROW LEVEL SECURITY;

-- Policy: Only owner can view or update their farm boundaries
CREATE POLICY "Farmers can only access their own parcel data"
ON fields FOR ALL
USING (auth.uid() = owner_id);

-- Policy: Materialized view for policymakers (Only aggregate counts, zero PII)
CREATE MATERIALIZED VIEW regional_trends AS
SELECT 
  district, 
  AVG(ndvi_score) AS avg_ndvi, 
  COUNT(id) AS total_farms
FROM fields
GROUP BY district;

Q9: Exactly what is NDVI, which satellite bands do you use, and what are the numerical thresholds?
Professor Trap ▼
Rookie Mistake: Saying "NDVI is greenness." Examiners will immediately deduct marks for vague answers.
Flawless Counter-Punch: "NDVI is the Normalized Difference Vegetation Index, calculated as (NIR - Red) / (NIR + Red). In Sentinel-2 MSI, we query Band 8 (Near-Infrared, 842nm) and Band 4 (Red, 665nm) at 10-meter spatial resolution.
• < 0.1: Bare soil, rock, water, or sand.
• 0.2 to 0.4: Sparse, budding, or water-stressed vegetation.
• 0.5 to 0.8+: High-density, healthy, actively photosynthesizing canopy."
